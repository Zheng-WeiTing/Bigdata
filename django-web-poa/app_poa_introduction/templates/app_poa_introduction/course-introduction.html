新聞爬蟲與斷詞流程介紹

功能概述

本模組透過 爬蟲 ➝ 中文斷詞 ➝ 關鍵詞分析 三階段流程，自動化擷取新聞網站內容，並使用 CKIPTagger 萃取具代表性的動詞與名詞詞彙。結合 TF-IDF 與詞彙分類技術，應用於情緒分析與議題關注趨勢探索。

詳細介紹

使用 requests 與 BeautifulSoup 擷取新聞列表與文章 HTML，整理新聞標題、時間、連結、圖片與內文，並儲存為結構化資料。
  • 模擬 GET 請求取得 HTML
  • 擷取各欄位（標題、時間、內容）
  • 清除冗餘標籤與廣告內容
  • 儲存為結構化 CSV

利用 CKIPTagger 處理新聞內文，切分成詞彙並標註詞性，篩選出具意義的名詞與動詞。
  • 分詞處理 → 拆解句子為詞組
  • 詞性標註 → 選取關鍵詞性（如動詞、名詞）
  • 清除虛詞、標點與無意義字

使用 Counter 統計詞頻，搭配 TF-IDF 權重找出代表詞，並對詞彙進行分類，應用於議題分析與圖表呈現。
  • 詞頻統計（Counter）
  • TF-IDF 分數加權代表詞
  • 詞彙分類：人物、事件、情緒
  • 產生文字雲、長條圖等視覺化

爬蟲與斷詞流程介紹

功能概述

本系統透過三階段流程：職缺資料擷取 → 中文斷詞處理 → 關鍵詞統計分析，自動化擷取與理解 104 人力銀行 職缺網頁內容。分析結果應用於技能詞彙擷取、特質分類、薪資條件分析等模組，協助使用者掌握就業趨勢與職場需求。

詳細介紹

使用 Selenium 模擬瀏覽器動作，自動滑動與翻頁擷取 JSON/HTML，再透過 requests 與 BeautifulSoup 解析職缺內容欄位。
  • 模擬點擊與載入（Selenium）
  • 遍歷多職類與分頁
  • 擷取職稱、薪資、福利等欄位
  • 儲存為 Pandas DataFrame / CSV

透過 CKIPTagger 對職缺說明進行繁體中文斷詞與詞性標註，篩選出具代表性的動詞與名詞。
  • CKIP 分詞 → 拆解句子為詞組
  • 詞性標註 → 萃取動詞與名詞
  • 建立職缺關鍵詞清單

統計職缺中關鍵詞的詞頻，搭配 TF-IDF 權重計算代表性詞彙，並對應至技能、特質、條件進行分類視覺化。
  • Counter 計算詞頻
  • TF-IDF 分析代表詞
  • 詞彙分類與圖表呈現
